## Canvas-Specific Rules

### Font: Nunito in canvas (not Baloo 2)

Baloo 2 does not rasterize cleanly in Phaser's BitmapText / Text pipeline. Use **Nunito** for all in-canvas text. Nunito has full Romanian diacritic coverage and renders crisply at game resolutions.

- In-canvas text: **Nunito Bold / Black** only.
- DOM-rendered HUD overlays (HTML, not canvas): follow `edu-play-core/.impeccable.md` — Baloo 2 there.

### Touch targets in canvas

Canvas tap targets: **≥ 88 × 88 px** (larger than the shell floor of 64 px). Hit areas should be invisible extensions of the visual asset — prefer larger hit area over shrinking the artwork.

### In-canvas feedback

| Outcome | Visual | Audio |
|---------|--------|-------|
| Correct | Confetti + star burst + mascot wiggle | Celebratory jingle |
| Incorrect | Warm orange "Aproape!" label | Soft encouraging note |
| Session end | Full-screen celebration + play-again prompt | Victory sting |

Hard fails for canvas feedback:

- ❌ Red X or red flash for wrong answers
- ❌ "Game over" screen with no play-again path
- ❌ Buzzer / harsh error sound
- ❌ Prominent "wrong count" display

### Config-driven themes

Themes ship as color + mascot pairs: `nature`, `ocean`, `space`, `candy`, `forest`, `sunset`, `default`. Never bake a one-off palette into a scene. New themes extend the shared theme registry — they do not fork a scene.

### No emoji in canvas

Unicode emoji render inconsistently across devices and Phaser versions. Use drawn Graphics objects, sprites, or particle effects instead. (Emoji in Romanian DOM copy is fine per the canonical checklist.)

### Audio

- Every audio cue must have a visible counterpart — visual feedback is never audio-only.
- Respect browser autoplay policy: gate audio on user interaction before the first `play()` attempt; never block gameplay waiting on a play promise.

### Canvas motion presets

| Action | Preset |
|--------|--------|
| Card / object entrance | `Back.easeOut` bounce |
| Tap / select feedback | Scale 0.95 + y-offset shadow pull-down |
| Correct answer | Confetti burst + star scale pop |
| Idle mascot loop | Bob (2 s scale 0.98 ↔ 1.02) — **disabled** when reduced-motion is active |

The reduced-motion flag is passed from the host via the postMessage config handshake. Idle loops must check it before starting.

### Vulpița is not in canvas

Phaser games own their own in-canvas visual language. Do not import or render the Vulpița SVG inside a Phaser scene. Use game-specific sprites and particle celebrations instead.
